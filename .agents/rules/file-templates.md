# File Templete

* Activation: Model Decision
* Trigger: Apply whenever instructed to create a new source or header file.
* This document defines the standard template that every newly created source file must follow.
* File names must be in PascalCase

## Configuration Header (.hpp)

Use this template strictly for configuration headers. This file should contain NO logic, NO functions, and NO class definitions. It is reserved for compile-time constants (`constexpr`), macros, and configuration structures.

```cpp
/******************************************************************************
 * @file
 * @brief
 *
 * Author : Huwairis Ibnu Kabeer
 * License: MIT
 ******************************************************************************/

#pragma once

/*==========================================================================*/
/* Includes                                                                 */
/*==========================================================================*/

/*==========================================================================*/
/* Namespace                                                                */
/*==========================================================================*/

namespace example {
namespace nested_example { // Optional nested namespace for strict scoping

/*==========================================================================*/
/* constant Expressions                                                     */
/*==========================================================================*/

/*==========================================================================*/
/* Enumerations                                                             */
/*==========================================================================*/

/*==========================================================================*/
/* Structures                                                               */
/*==========================================================================*/

/*==========================================================================*/
/* Global Variables / Configuration / Lookup Tables                         */
/*==========================================================================*/
// extern int example;
// Do not add globals directly in header files, it could cause linker issues
// Instead create a source file for it

/*==========================================================================*/
/* Classes                                                                  */
/*==========================================================================*/

} // namespace nested_example
} // namespace example

```
